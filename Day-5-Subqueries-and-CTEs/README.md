# Subqueries and CTEs

This section demonstrates intermediate-to-advanced SQL techniques using the AdventureWorks product and internet sales data in MySQL.

## Business questions answered

- Which products are priced above the overall average?
- Which products have appeared in sales, and which have never sold?
- Which products are priced above the average for their own product line?
- How far is each product price from the overall average?
- Which product lines meet minimum size and price thresholds?
- Which products generate above-average total sales?
- Which products are priced above every product in a selected line?
- How can a recursive CTE generate a complete monthly calendar?

## SQL techniques

- Scalar and multiple-row subqueries
- Correlated subqueries
- IN, EXISTS and NOT EXISTS
- Subqueries in SELECT, WHERE and FROM
- Derived tables
- Common Table Expressions
- Multiple dependent CTEs
- ALL comparisons
- Recursive CTEs
- Aggregation, joins and business-focused filtering
